A short, hands-on primer

JavaScript, start to finish

Six ideas that carry the whole language: variables, functions, conditionals, loops, arrays, and objects. Read a bit, then run it yourself in the editor built into this page — no installs, no account, no other tab.

1. Variables

A variable is a named box for a value. Use let when the value will change, and const when it won't.

let score = 10;
score = score + 5;

const name = "Ada";

console.log(score, name);

2. Functions

A function packages up a piece of logic so you can reuse it with different inputs.

function greet(person) {
  return "Hello, " + person + "!";
}

console.log(greet("world"));

3. Conditionals

if / else lets your program choose between paths based on a condition.

const hour = 14;

if (hour < 12) {
  console.log("Good morning");
} else if (hour < 18) {
  console.log("Good afternoon");
} else {
  console.log("Good evening");
}

4. Loops

A for loop repeats a block of code while a condition holds.

for (let i = 1; i <= 5; i++) {
  console.log("Round " + i);
}

5. Arrays

An array holds an ordered list of values. Methods like map and filter let you transform a list without writing a manual loop.

const fruits = ["apple", "fig", "kiwi"];
const shouted = fruits.map(f => f.toUpperCase());

console.log(shouted);

6. Objects

An object groups related values together under named keys — useful for describing a single "thing" with several properties.

const book = {
  title: "Dune",
  author: "Frank Herbert",
  year: 1965
};

console.log(book.title + " (" + book.year + ")");
